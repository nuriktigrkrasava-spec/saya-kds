# Saya KDS — перехват кухонной печати (зал без iiko-лицензии)

iikoFront печатает кухонные марки на сетевой принтер (raw ESC/POS, порт 9100).
Эта утилита прикидывается таким принтером: ловит задание печати и (после
настройки парсера) шлёт заказ в Saya KDS `/ingest/front`. Лицензия плагина
и обращение в iiko НЕ нужны.

## Где запускать
На любом ПК в **той же сети, что и касса** (можно на самом кассовом ПК).
Нужен установленный **.NET SDK** (у тебя уже есть).

## Шаг 1 — снять формат чека (сейчас)
1. Скачай папку `iiko-print-capture` (Program.cs, SayaPrintCapture.csproj).
2. В этой папке запусти:
   ```
   dotnet run
   ```
   Увидишь: `[SayaPrint] слушаю порт 9100`.
3. Узнай **IP этого ПК**: в cmd `ipconfig` → IPv4-адрес (напр. 192.168.0.50).
4. В **iikoOffice** настрой печать одной кухонной группы (роллы/пицца) на
   **сетевой принтер**: тип — Ethernet/Windows, адрес = IP этого ПК, порт `9100`.
5. Пробей тестовый заказ зала → утилита поймает печать, выведет текст и запишет
   в файл **`capture.txt`**.
6. **Пришли содержимое `capture.txt`** — по нему я напишу парсер (номер заказа,
   блюда, количество, комментарии) и форвард в `/ingest/front`.

## Шаг 2 — парсинг + отправка (после того как пришлёшь capture.txt)
Добавлю разбор реального формата и отправку заказа на планшет. Тогда зал поедет
в KDS без iiko.

## Замечания
- Если на ПК нет .NET 10 — поменяй в `.csproj` `net10.0` на `net8.0`.
- Порт по умолчанию 9100; другой: `dotnet run -- 9101`.
- Брандмауэр Windows может спросить разрешение на порт — разреши (частная сеть).

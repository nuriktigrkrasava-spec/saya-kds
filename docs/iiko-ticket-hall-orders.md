# Письмо в поддержку iiko API — состав заказов зала не выгружается в Cloud

Отправлять ответом в тикет **#ID-361951845** на `iiko_client_api@iiko.ru`.

---

**Тема:** Заказы зала: состав не выгружается в Cloud, пока заказ открыт — сеть Saya, Астана

Здравствуйте.

Возвращаемся к тикету #ID-361951845. После вашей доработки в начале июля заказы
зала начали приходить в Cloud и наш кухонный экран работал. Сейчас поведение
изменилось снова, но иначе, чем было в июне.

**Суть проблемы**

`POST /api/1/order/by_table` возвращает открытый заказ зала с **пустым массивом
`items`**. Состав появляется только после закрытия заказа. Для кухонного экрана
это бесполезно: заказ нужен кухне, пока он открыт.

**Воспроизведение (Астана, ул. Г.Алиева 10 (EXPO))**

- organizationId: `d9a4272f-65f0-4e56-8846-434f2348889c`
- terminalGroupId: `013381aa-f566-4796-9430-46314662ca93`
- Порядок: `POST /api/1/order/init_by_table` (200 OK) → `POST /api/1/order/by_table`

Запрос со статусами `["New", "Bill"]` 15.08.2026 в 14:25 (UTC+5) вернул заказ,
пробитый в зале минутой ранее:

```json
{
  "number": 26,
  "status": "New",
  "whenCreated": "2026-08-15 14:23:32.735",
  "items": [],
  "sum": 0.0,
  "orderType": { "name": "Обычный заказ", "orderServiceType": "Common" }
}
```

Заказ существует, открыт, но состава нет.

Тот же метод со статусом `["Closed"]` по этой же организации возвращает **2835
заказов, и у всех `items` заполнен**. То есть данные в системе есть — они просто
не отдаются, пока заказ не закрыт.

**Вебхук `TableOrderUpdate` не приходит**

Подписка активна и подтверждается в `POST /api/1/webhooks/settings`:

- `webHooksUri`: `https://saya-kds-irlg.onrender.com/webhooks/iiko/cloud`
- `tableOrderFilter.orderStatuses`: `["New", "Bill", "Closed", "Deleted"]`

Подписку переоформили заново 15.08.2026. За неделю наблюдения на наш адрес не
пришло **ни одного** события `TableOrderUpdate`, при том что заказы зала в
филиале пробиваются постоянно (по OLAP — около 100 в день). События
`DeliveryOrderUpdate` по этой же подписке также не приходят, доставку мы
вынуждены забирать поллингом.
